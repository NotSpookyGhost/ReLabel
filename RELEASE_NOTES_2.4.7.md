# ReLabel 2.4.7 - Empty-list import shortcut (local test build)

- Replaced the empty-list message with a centered plus icon inside a rounded outline and short drag-and-drop/hotfolder instructions.
- Clicking the plus opens a PDF file picker supporting multiple files. Keyboard activation is also supported.
- File-picker imports share the existing background copy, duplicate-name handling, and import/security pipeline with drag and drop.
- Drag-and-drop feedback remains available across the main window, including the new empty-list controls.

Existing settings and folder paths are preserved. This is a local test installer, not a published or GitHub-attested release.
